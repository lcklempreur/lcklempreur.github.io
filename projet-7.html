Déploiement PXE – FOG Project

Projet
BTS SIO SISR – E6
Période
Mars – Mai 2026
Serveur
srv-fog – Ubuntu Server 22.04 LTS
Domaine
AD Windows Server 2022 existant

Stack technique

FOG Project Ubuntu Server 22.04 PXE Boot TFTP Apache MySQL NFS Windows Server 2022 Active Directory DHCP options 66/67 FOG Client VMware Workstation

Objectif du projet

Mettre en place une solution de déploiement automatisé de postes informatiques avec FOG Project sur Ubuntu Server, intégrée à l'infrastructure Active Directory Windows Server 2022 existante. L'objectif est de centraliser la capture et le déploiement d'images Windows via boot PXE, et d'automatiser la jonction au domaine AD après déploiement.

"Déploiement centralisé de postes Windows via PXE intégré à l'Active Directory : capturer une fois, déployer partout."

Architecture

MachineRôleOS
srv-fogServeur FOG (Apache, TFTP, NFS, MySQL)Ubuntu Server 22.04
SRV-ADActive Directory, DNS, DHCP (options 66/67)Windows Server 2022
VM clientePoste à capturer / déployerWindows 10/11
VM cliente (boot PXE) → DHCP (options 66/67) → TFTP (srv-fog)
↓
Interface web FOG → Capture / Déploiement image → Jonction AD automatique

Travaux réalisés

1. Installation du serveur FOG sur Ubuntu Server 22.04
  • Exécution du script d'installation officiel FOG (Apache, TFTP, NFS, MySQL configurés automatiquement)
  • Accès à l'interface web FOG : http://IP_FOG/fog/management
  • Vérification des services : Apache, FOGMulticastManager, FOGImageReplicator
2. Configuration DHCP sur Windows Server 2022
  • Option 66 (Boot Server Host Name) → IP du serveur FOG
  • Option 67 (Bootfile Name) → undionly.kpxe (BIOS) / ipxe.efi (UEFI)
  • Test de boot PXE depuis une VM cliente vierge
3. Capture et déploiement d'image Windows
  • Enregistrement de la VM cliente dans FOG (via boot PXE → auto-enregistrement)
  • Capture de l'image disque Windows 10/11 (type : Single disk – Multiple partitions)
  • Déploiement de l'image sur une VM cliente vierge via tâche FOG
4. Jonction automatique au domaine AD
  • Installation du FOG Client sur le poste maître avant capture
  • Configuration de la jonction automatique au domaine AD dans FOG
  • Vérification : poste déployé rejoint automatiquement le domaine srvlog.lan

Résultats obtenus

  • Serveur FOG opérationnel avec interface web de gestion des hôtes et images
  • Capture d'image Windows réussie et stockée sur le serveur
  • Déploiement automatisé via PXE fonctionnel sur VM cliente
  • Jonction automatique au domaine AD après déploiement
  • Documentation complète : procédures, schéma réseau, captures d'écran, incidents résolus
