Déploiement d'Active Directory

Objectif du projet

Déploiement complet d'une infrastructure Active Directory sous Windows Server 2019 avec mise en place d'une topologie réseau complète incluant services DNS, DHCP et WDS pour une gestion centralisée des utilisateurs et ressources informatiques.

Phrase récapitulative

"Mise en place d'une infrastructure Active Directory complète avec déploiement automatisé de postes clients, gestion centralisée des utilisateurs et application de la stratégie de sécurité AGDLP."

Technologies et Compétences Mises en Œuvre

  • Serveur : Windows Server 2019 Datacenter
  • Services : Active Directory, DNS, DHCP, WDS
  • Client : Windows 10 Professionnel
  • Scripting : PowerShell pour automatisation
  • Réseau : Configuration TCP/IP, VLAN, réservations DHCP
  • Sécurité : Stratégie AGDLP, GPO

Architecture mise en place

Configuration d'un domaine "formation.lan" avec les services essentiels :

  • Contrôleur de domaine principal (DC19AD)
  • Service DNS intégré pour la résolution de noms
  • Serveur DHCP avec plage 192.168.10.0/24
  • Windows Deployment Services (WDS) pour déploiement réseau
  • Unités d'organisation (OU) structurées par services

Automatisation et scripting

Développement de scripts PowerShell pour :

  • Création automatique des OU, groupes et utilisateurs
  • Application de la stratégie de sécurité AGDLP
  • Gestion des profils itinérants
  • Automatisation des tâches d'administration

Résultats et bénéfices

Cette infrastructure a permis une gestion centralisée et sécurisée du parc informatique avec :

  • Authentification unique pour tous les utilisateurs
  • Déploiement automatisé des postes de travail
  • Gestion granulaire des permissions via GPO
  • Réduction du temps d'administration
  • Meilleure sécurité et traçabilité

Défis techniques relevés

  • Intégration des services : Configuration optimale DNS/AD
  • Déploiement WDS : Mise en place d'images de déploiement
  • Scripting avancé : Automatisation de la création d'objets AD
  • Sécurité : Application stricte du modèle AGDLP
