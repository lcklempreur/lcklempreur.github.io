Déploiement d'Active Directory

Serveur
Windows Server 2022 Datacenter
Domaine
formation.lan
Active DirectoryDNSDHCP WDSPowerShellGPOAGDLP

Objectif

Déploiement complet d'une infrastructure Active Directory sous Windows Server 2022 avec mise en place des services DNS, DHCP et WDS pour une gestion centralisée des utilisateurs et ressources informatiques.

"Mise en place d'une infrastructure AD complète avec déploiement automatisé de postes clients, gestion centralisée des utilisateurs et application de la stratégie de sécurité AGDLP."

Architecture

  • Contrôleur de domaine principal (DC22AD) – Windows Server 2022
  • Service DNS intégré pour la résolution de noms
  • Serveur DHCP avec plage 192.168.10.0/24
  • Windows Deployment Services (WDS) pour déploiement réseau
  • Unités d'organisation (OU) structurées par services

Automatisation PowerShell

Scripts développés
  • Création automatique des OU, groupes et utilisateurs
  • Application de la stratégie de sécurité AGDLP
  • Gestion des profils itinérants

Résultats

  • Authentification unique pour tous les utilisateurs du domaine
  • Déploiement automatisé des postes de travail via WDS
  • Gestion granulaire des permissions via GPO
  • Réduction du temps d'administration
