Projet : Déploiement de GLPI & FusionInventory

Objectif du projet

Déployer une solution complète de gestion de parc informatique pour une entreprise de 50 postes. L'objectif était de centraliser la gestion des actifs informatiques, suivre les interventions via un système de tickets et automatiser l'inventaire des équipements.

Technologies et Compétences Mises en Œuvre

  • Gestion de parc : GLPI 10.x
  • Inventaire automatique : FusionInventory/GLPI Agent
  • Serveur web : Apache 2.4
  • Base de données : MySQL 8.0
  • Système : Windows Server 2022, déploiement GPO

Fonctionnalités implémentées :

  • Gestion centralisée des tickets d'incidents
  • Inventaire automatique du matériel et logiciels
  • Gestion des contrats de maintenance
  • Suivi des consommables (toners, etc.)
  • Tableaux de bord de reporting

Démarche et Résultats

J'ai d'abord installé et configuré GLPI sur un serveur dédié avec Apache et MySQL. L'intégration de FusionInventory a permis l'inventaire automatique de tous les postes via des agents déployés par GPO. La configuration inclut :

  • Création de catégories personnalisées pour les équipements
  • Mise en place de workflows pour la gestion des tickets
  • Configuration des alertes pour les équipements critiques
  • Formation des utilisateurs à la création de tickets

Résultats : Réduction de 70% du temps de résolution des incidents, meilleure visibilité sur le parc informatique, et automatisation des tâches d'inventaire.

Défis rencontrés et solutions :

  • Déploiement des agents : Résolu par l'utilisation des GPO Windows
  • Performance de la base de données : Optimisation des index MySQL
  • Formation utilisateurs : Création de documentation et sessions de formation
